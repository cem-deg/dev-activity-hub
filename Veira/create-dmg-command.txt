# Veira Release / Export Checklist

## 1) Version güncelle

Veira/project.yml içinde:

MARKETING_VERSION: "1.5.0"
CURRENT_PROJECT_VERSION: "10"

Kural:
- MARKETING_VERSION kullanıcıya görünen sürüm
- CURRENT_PROJECT_VERSION build number
- Build number her release’te artmalı

## 2) Xcode project regenerate

Terminal:

cd Veira
xcodegen generate
open Veira.xcodeproj

## 3) Archive al

Xcode:

Product → Archive

Archive ekranında solda version/build doğru görünmeli:

1.5.0 (10)

## 4) Export al

Organizer:

Distribute App
→ Direct Distribution
→ Next
→ Next
→ bekle

Not:
- In Progress normal olabilir.
- Notarization birkaç dakika sürebilir.
- Bittiğinde export klasörü seçtirir.

## 5) Export edilen app’i kontrol et

Export edilen Veira.app klasörünün olduğu yerde:

defaults read "Veira.app/Contents/Info" CFBundleShortVersionString
defaults read "Veira.app/Contents/Info" CFBundleVersion

Beklenen:
1.X.X
BUILD_NUMBER

Signing kontrolü:

codesign -dv --verbose=4 Veira.app

Beklenen:
TeamIdentifier dolu olmalı.
Signature artık adhoc olmamalı.

## 5.5) xattr temizle (ZORUNLU — DMG’den önce yapılmalı)

# Neden gerekli:
# Proje iCloud Drive ile senkronize bir klasörde (örn. ~/Documents/GitHub/) ise
# iCloud File Provider daemon, Sparkle.framework içindeki dosyalara otomatik olarak
# com.apple.FinderInfo ve com.apple.fileprovider.fpfs#P xattr’ları ekler.
# Bu xattr’lar notarization’ı bozmaz ama codesign --strict kontrolünü geçemez.
# spctl/Gatekeeper kabul eder; kullanıcı deneyimi etkilenmez.
# xattr temizlemek code signature hash’ini etkilemez — güvenlidir.
#
# ÖNEMLI: İCloud bu xattr’ları saniyeler içinde tekrar ekler.
# Bu yüzden app önce /tmp’ye (iCloud dışına) kopyalanmalı,
# oradan strip edilmeli, ve create-dmg /tmp’deki kopya üzerinden çalışmalıdır.

# Adım 1: /tmp’ye kopyala (iCloud takip xattr’ını da atar)
mkdir -p /tmp/VeiraRelease
ditto --noextattr /EXPORT_KLASÖRÜ/Veira.app /tmp/VeiraRelease/Veira.app

# Adım 2: Kalan FinderInfo xattr’larını temizle
xattr -cr /tmp/VeiraRelease/Veira.app

# Adım 3: Doğrula
xattr -lr /tmp/VeiraRelease/Veira.app
# Beklenen: com.apple.FinderInfo veya com.apple.fileprovider.fpfs#P olmamalı.
# macOS com.apple.provenance gösterebilir; strict codesign geçiyorsa bu kabul edilebilir.

codesign --verify --deep --strict --verbose=2 /tmp/VeiraRelease/Veira.app
# Beklenen: hata çıkmamalı; "valid on disk" ve "satisfies its Designated Requirement"

spctl -a -vv -t exec /tmp/VeiraRelease/Veira.app
# Beklenen: source=Notarized Developer ID

Bu adım geçilmeden DMG oluşturulmamalı.

## 6) DMG oluştur

/tmp/VeiraRelease klasöründe (iCloud dışında — adım 5.5 sonrası):

cd /tmp/VeiraRelease

create-dmg \
  --volname "Veira" \
  --window-size 600 400 \
  --icon-size 120 \
  --icon "Veira.app" 150 200 \
  --app-drop-link 450 200 \
  "Veira.dmg" \
  "Veira.app"

# DMG /tmp içinde kalmalı. Önce bu kopya doğrulanır ve Sparkle ile imzalanır.
# GitHub'a yüklemek için release klasörüne kopyalama adımı 8'den sonra yapılır.

## 7) DMG içini kontrol et

hdiutil attach /tmp/VeiraRelease/Veira.dmg

defaults read "/Volumes/Veira/Veira.app/Contents/Info" CFBundleShortVersionString
defaults read "/Volumes/Veira/Veira.app/Contents/Info" CFBundleVersion

Beklenen:
1.X.X
BUILD_NUMBER

Strict codesign kontrolü (DMG içindeki app üzerinde):

codesign --verify --deep --strict --verbose=2 "/Volumes/Veira/Veira.app"

Beklenen:
(hata çıkmamalı — "valid on disk" ve "satisfies its Designated Requirement" görünmeli)

spctl kontrolü:

spctl -a -vv -t exec "/Volumes/Veira/Veira.app"

Beklenen:
source=Notarized Developer ID

hdiutil detach "/Volumes/Veira"

NOT: Bu üç kontrol geçilmeden 8. adıma geçilmemelidir.

## 8) Sparkle imzası al

DMG /tmp içindeki temiz kopyadan imzalanmalı:

find ~/Library/Developer/Xcode/DerivedData -path "*/Sparkle/bin/sign_update" -type f | head -1

Çıkan path’i kullan:

"ÇIKAN_PATH" /tmp/VeiraRelease/Veira.dmg

Çıktıdan şunları sakla:
- sparkle:edSignature
- length

GitHub'a yükleyebilmek için DMG'yi ilgili versioned release klasörüne kopyala:

mkdir -p Veira/Releases/Veira_V1.5.0
cp /tmp/VeiraRelease/Veira.dmg Veira/Releases/Veira_V1.5.0/Veira.dmg

## 9) GitHub Release oluştur

GitHub → Releases → Draft new release

Tag:
v1.5.0

Title:
Veira v1.5.0

Asset:
Veira/Releases/Veira_V1.5.0/Veira.dmg

Publish release.

## 10) appcast.xml güncelle

Repo root’taki appcast.xml içinde en yeni item en üste eklenmeli:

<item>
  <title>Veira 1.5.0</title>
  <sparkle:version>10</sparkle:version>
  <sparkle:shortVersionString>1.5.0</sparkle:shortVersionString>
  <sparkle:minimumSystemVersion>14.0</sparkle:minimumSystemVersion>
  <enclosure
    url="https://github.com/cem-deg/Veira-activity-menubar/releases/download/v1.5.0/Veira.dmg"
    sparkle:edSignature="BURAYA_SIGNATURE"
    length="BURAYA_LENGTH"
    type="application/octet-stream"/>
</item>

## 11) Push

git add appcast.xml Veira/project.yml Veira/Veira.xcodeproj/project.pbxproj Veira/create-dmg-command.txt Veira/App/Info.plist
# Ayrıca bu release'e ait değişen source/config dosyalarını da ekle.
git commit -m "release v1.5.0"
git push
